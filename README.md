# Практическое задание №3 «Практика pipeline»

# Coffee Sales ML Pipeline & Orchestration

Практический проект по разработке полного цикла машинного обучения для классификации кофейных напитков на основе датасета `Coffe_sales.csv`.

## 🚀 Основные этапы проекта

1. **Разведочный анализ и подготовка данных (EDA):**
   * Загрузка и первичный анализ датасета, проверка пропусков и распределения целевой переменной `coffee_name`.
   * Форматирование признака даты (`Date`).

2. **Инженерия признаков (Feature Engineering):**
   * Создание новых признаков на основе даты: день месяца (`day_of_month`), номер недели в году (`week_of_year`) и признак выходного дня (`is_weekend`).
   * Формирование матриц признаков и разделение выборки со стратификацией (`train_test_split`, `stratify=y`).

3. **Построение ML-пайплайна (`Pipeline` & `ColumnTransformer`):**
   * Раздельная предобработка числовых (`StandardScaler`) и категориальных (`OneHotEncoder`) признаков.
   * Объединение препроцессора и моделей в единый пайплайн scikit-learn.

4. **Обучение и валидация моделей:**
   * Обучение бейзлайна (`DummyClassifier`) и трех базовых моделей с кросс-валидацией (`StratifiedKFold`, 5 фолдов).
   * Фиксация метрик `Accuracy` и `F1-macro` на кросс-валидации и тесте.

5. **Оптимизация гиперпараметров:**
   * Подбор гиперпараметров для лучшей модели с помощью фреймворка **Optuna**.
   * Переобучение финальной оптимизированной модели (Градиентный бустинг).

6. **Трекинг экспериментов в MLflow:**
   * Логирование параметров, метрик и артефактов для каждого запуска (бейзлайн, модели сравнения, оптимизированный вариант).
   * Визуализация и сравнение результатов через веб-интерфейс MLflow UI.

7. **Оркестрация процессов (Airflow DAG):**
   * Автоматизация пайплайна с помощью DAG (`coffee_sales_ml_pipeline`), состоящего из трех последовательных задач: загрузка данных, feature engineering и обучение с логированием.
   * Установлено еженедельное расписание (`schedule_interval='@weekly'`).
